## 🔵 dotpy

Plataforma de dados para empresas de médio porte, sem precisar de um time de dados.

- 🔌 Dados de planilhas, arquivos e bancos num só lugar, num ambiente isolado por empresa
- 🧩 Pipelines montados arrastando caixinhas: a dotpy escreve o código, roda no horário ou quando o dado chega e guarda cada versão
- 📈 Indicadores como numa tabela dinâmica, com atualização automática e histórico
- ✅ Matriz RACI, formulários, telas sob medida e tarefas da equipe no mesmo console
- 🤖 Assistente de IA que trabalha só com a estrutura dos dados, nunca com os registros (em breve)
